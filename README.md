<p dir="auto"><strong>English</strong></p>
<p dir="auto">About the Project</p>
<p dir="auto">Anonymous Message Bot is an open-source Telegram bot designed to let users receive anonymous messages through a personal link.</p>
<p dir="auto">Features</p>

<ul dir="auto">
 	<li><strong>🔗 Personal anonymous message link for each user</strong></li>
 	<li><strong>💬 Receive messages anonymously</strong></li>
 	<li><strong>🔒 Keeps the sender’s identity hidden</strong></li>
 	<li><strong>🤖 Telegram bot-based interface</strong></li>
 	<li><strong>📩 Forward received messages to the recipient</strong></li>
 	<li><strong>🛠️ Simple and easy-to-use interaction</strong></li>
 	<li><strong>⚙️ Configurable through environment variables</strong></li>
 	<li><strong>🗄️ SQLite database for storing bot data</strong></li>
</ul>
<p dir="auto">Configuration</p>
<p dir="auto">The bot uses environment variables for sensitive information such as:</p>

<ul dir="auto">
 	<li dir="ltr"><span style="color: #ff0000;"><strong>Telegram Bot Token</strong></span></li>
 	<li dir="ltr"><span style="color: #ff0000;"><strong>Admin ID</strong></span></li>
 	<li dir="ltr"><span style="color: #ff0000;"><strong>Bot Username</strong></span></li>
 	<li dir="ltr"><span style="color: #ff0000;"><strong>Channel Username</strong></span></li>
 	<li dir="ltr"><span style="color: #ff0000;"><strong>API Token</strong></span></li>
 	<li dir="ltr"><span style="color: #ff0000;"><strong>Database path</strong></span></li>
</ul>
<p dir="auto">Sensitive credentials should be stored in .env and must never be committed to GitHub.</p>
<p dir="auto">⸻</p>
<p dir="auto"><strong>فارسی</strong></p>
<p dir="auto">درباره پروژه</p>
<p dir="auto">ربات پیام ناشناس یک پروژه متن‌باز برای تلگرام است که به کاربران امکان می‌دهد از طریق لینک اختصاصی خود، پیام‌های ناشناس دریافت کنند.</p>
<p dir="auto">امکانات</p>

<ul dir="auto">
 	<li><strong>🔗 ایجاد لینک اختصاصی برای هر کاربر</strong></li>
 	<li><strong>💬 دریافت پیام‌های ناشناس</strong></li>
 	<li><strong>🔒 مخفی ماندن هویت ارسال‌کننده</strong></li>
 	<li><strong>🤖 رابط کاربری مبتنی بر ربات تلگرام</strong></li>
 	<li><strong>📩 ارسال پیام دریافت‌شده برای صاحب لینک</strong></li>
 	<li><strong>🛠️ استفاده ساده و سریع</strong></li>
 	<li><strong>⚙️ امکان تنظیم اطلاعات از طریق متغیرهای محیطی</strong></li>
 	<li><strong>🗄️ استفاده از دیتابیس SQLite</strong></li>
</ul>
<p dir="auto">تنظیمات</p>
<p dir="auto">اطلاعات حساس مانند توکن ربات، شناسه ادمین و API Token باید در فایل .env قرار بگیرند و نباید در GitHub منتشر شوند.</p>
